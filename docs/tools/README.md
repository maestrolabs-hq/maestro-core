# Tools

This directory contains one page per operator tool. A tool sits at the human
boundary rather than inside the engine: the operator runs it directly.

| Tool page | Role | Upstream |
| --- | --- | --- |
| [Docling](./docling.md) | Local document conversion (PDF, DOCX, and more) to structured Markdown/JSON | `docling-project/docling` |
| [Plannotator](./plannotator.md) | Human review surface for plans, documents, and diffs; annotations return to the agent | `backnotprop/plannotator` |
