# Source preparation: choose the native stage, preserve evidence

Inventory inspected 2026-09-05 for the versions in [capabilities](capabilities.md).
This is **not** a universal cleaner chain. `used`/`verified-used` means the
named isolated audit fixture exercised the helper, not that it is wired into
production. `unsafe` means bypass or guard for this corpus/policy;
`not-applicable`, `unavailable`, and `untested` are explicit dispositions.
Source-only APIs are availability evidence, not quality results.

For all seven providers: permission/model route -> canonical source eligibility
-> preserve original bytes/hash/observed checkout -> format-specific parser
-> bounded source-aware chunks if needed -> approved extraction -> exact
span/quote/polarity/modality checks -> provider-local duplicate/conflict review
-> structural validation -> approved persistence -> scoped query/reload checks.
AST parsers receive unmodified code. Inline-code contents, negation, paragraph
and table boundaries, repeated occurrences, source spans and provenance survive
until assertion admission. Keep meaningful null validity values. Source text is
data, not executable instructions; no cleaner makes arbitrary prompts safe.

The shared preflight is tracked at
`maestro-pi-config/config/pi/skills/provider-fanout/preflight.py`. It verifies
one of the eight canonical Git roots under an explicit workspace, including
`.git` files, topic branches and eligible dirty files; it rejects escaping
source symlinks and skips generated components at any depth. Directory symlinks
are deliberately refused to avoid provider-specific traversal/loop behavior.
It does not configure provider ignores, redact secrets, lock the checkout or
reconcile old production indexes. `.cgcignore` was untracked in all eight roots;
`.cbmignore` absent; CBM had indexed graphify-out artifacts. Production cleanup
is still blocked pending native exclusion/removal validation and approval.

Available boundary tools: Git, pathlib, hashlib, strict byte decoding, native
read-only SQLite/Kuzu inspection. gitleaks/trufflehog/detect-secrets were not
on PATH; none was installed. Absence of a scanner is not permission to export
sensitive sources. Exclude/redact before inference with explicit coverage and
mapping; never rewrite original files or print credentials.

Native source references are package-relative: CGC=codegraphcontext,
CG=CodeGraph native dist, CBM-src=upstream v0.10.8 (binary/source correspondence
corroborated, not rebuilt), PKG=semantica, G=graphify, M=mempalace,
D=docling_mcp. Internal APIs require the stated package version and independent
precondition checks; they are not automatically exposed MCP tools.

## Semantica

1. **Before parsing/inference:** validate canonical source identity/path and live worktree eligibility, preserve immutable original bytes and their content hash plus observed checkout identity; perform strict decoding; enforce source/sensitive-data eligibility and approved provider/model/endpoint/auth scope. Treat repository text as data, never executable instructions. Do not let a cleaner, LLM, parser fallback, or tool argument choose another route. No available TextCleaner method establishes secret redaction or prompt-injection safety. Keep credentials out of graph/text/cache/logs. Redaction/exclusion must retain an offset mapping and an explicit coverage reason; never mutate the original file.
2. **Parse structure, not punctuation:** for Markdown, the verified installed `MarkdownIt('commonmark').enable('table').parse(text)` preserves heading/paragraph/table-row line maps and `code_inline` content. Use its original line maps to select original source blocks. Do not join arbitrary rows into prose or discard code identifiers. Where structured table rows already exist, native TableChunker can bound rows and repeat headers; retain original row/line evidence separately. Source-specific JSON/CSV/code/document parsing is opt-in and coverage-tracked, not forced through Markdown.
3. **Chunk only when necessary:** preserve original block slices; maintain every occurrence. Check `chunk.text == original[start:end]` or an explicit mapped multi-span transformation before dispatch. The tested native recursive/structural paths currently fail this invariant, so do not blindly use their offsets. Prefer bounded original blocks and explicit unsupported/oversized-block accounting until the narrow offset bugs are fixed. Authorize every chunk's exact model/route, not only the first.
4. **Extract with the approved producer only.** The isolated audit verifies fixed reference and deterministic regex composition, not production ML quality. Confidence values, inferred labels, empty output, and generic adjacency are not grounding.
5. **After extraction:** source-slice/entailment/polarity/modality/temporal checks, structural DataValidator schema, then optional field-specific canonicalization and candidate duplicate/conflict detection. Keep meaningful nulls (`valid_until=None` means open-ended), all evidence occurrences, and competing claims. Resolve identity within Semantica's source/domain scope, never across provider graphs. Do not auto-merge or auto-resolve merely because a helper's score is high.
6. **Graph integrity and persistence:** validate the canonical `{entities,relationships}` structure and referential integrity before ContextGraph can auto-create missing endpoints. Native GraphValidator plus explicit evidence/identity/polarity checks; permit genuine isolated nodes without treating every warning as corruption. Then native GraphBuilder/ContextGraph composition with auto merge/conflict resolution disabled, safe persistence and fresh reload checks. Production write/load remains a separate approval checkpoint.

**Smallest verified components to reuse:** strict stdlib source read/hash, installed MarkdownIt line/inline/table tokens, native TableChunker for already structured rows, native DataValidator for explicit fields, native ConflictDetector for value disagreements (report, not resolve), native GraphValidator for edges/schema, then the already-proven native GraphBuilder/ContextGraph path. This is a component-level verified path, **not a delivered/wired full-quality pipeline**. Do not add every cleaner, embedding splitter, merger, and resolver in series.

## Preservation challenge cases and remaining failures

- `` `Maestro` does not implement `supervisor`. `` must retain both identifiers
  and negative polarity. The old untracked sanitizer returned `does not
  implement .`; it is bypassed, not promoted into provisioning.
- An authored dependency parse of `Aster does not use Birch.` produced an
  unqualified positive `use` relation. Keeping the word `not` alone does not
  repair extraction semantics. This remains failed/unfixed.
- Native recursive splitter offsets disagree with three of four original
  slices; explicit overlap zero becomes 200. Structural splitting flattens a
  table. These remain failed/unfixed: use original parser block slices, not
  those advertised offsets. No extraction adapter is delivered by the patch.
- ExtractionValidator accepts zero-length Aster span as valid/score1.0. That
  score is confidence, not F1 or entailment. Explicit original-slice equality
  and all evidence occurrences are mandatory before graph insertion.
- DataCleaner defaults drop `{id:a,valid_until:null}`. Bypass missing-value and
  duplicate removal or skip the cleaner; null is an open interval, not dirt.
- Graphify label sanitizer removes newlines; semantic sanitizer deletes
  rationale nodes/edges; native merge validates but does not call that cleaner.
  Keep display escaping after extraction and retain original rationale evidence.
- MemPalace long query sanitizer reduced a constrained 446-character request
  to `Which router exists?`; leading negation/exclusions disappeared. Inspect
  and bypass lossy query rewriting, never represent that tail as equivalent.
  Transcript-only strip_noise removes hook-looking lines even in code fences;
  it is unsafe on generic source prose/code. Production remains untouched.
- Docling preserves code-body syntax and negation in tested Markdown, but drops
  the fence language and provides no original spans (`prov=[]`). Inline code
  may be in adjacent items: include the negating context, not one isolated
  anchor. Derived Markdown reflows tables; retain original bytes and mapping.

These are separate from the selected guarded source fixes. Native patch tests
prove routing/serialization/analytics contracts, not all preparation invariants
or extraction quality. The [validation](validation.md) workflow must fail or
abstain on unsupported evidence rather than silently invent mappings/facts.
